Key Features

Designed for productivity. Built for daily use.

☰

Collapsible Sidebar

A persistent 240px left sidebar (configurable 180-360px) with full-text search, app icons, and a one-click collapse. Replaces the legacy app drawer with a modern, always-available navigation surface.

★

Personal Favorites Home

Pin any menu to a personal Favorites hub. Per-user, security-scoped, and opened automatically on every login — users land straight on what matters to them, with a live clock and full date in the corner.

🎬

Dynamic Home Background

Upload an image, GIF or short video and the Favorites Home plays it full-bleed behind a soft dim overlay. Text flips to light, tiles get a frosted-glass finish, and videos autoplay muted on loop — one setting, brand-perfect landing page.

☽

First-class Dark Mode

A dedicated dark palette, a navbar toggle, and persistent preference (localStorage). Every restyled view — lists, kanban, forms, dialogs — honours the chosen palette.

⚙

Visual Theme Settings

Pick colors, fonts, radius, density, shadow strength, sidebar width, and motion speed from a single Settings panel. Changes flow through CSS variables — no developer required.

🔒

4 Login Layouts

Centered Card, Split Screen, Full-Screen Background, and Minimal. Pick a layout, upload a background image, and the login / sign-up / password-reset pages all follow.

⚙

Custom App Icons

Override any root menu icon with your own image or a Font Awesome glyph. A built-in admin list lets you manage per-app overrides without code.

⚡

Profile Card & Quick Actions

A theme-coloured card greets the user with avatar, name and a time-of-day greeting, then offers one-click shortcuts: profile preferences, debug, theme settings, sidebar pin, dark mode, conversations, activities and sign-out. Live unread / pending badges and a toast notification on every change — and the entire top Odoo bar is hidden so the workspace starts at the very top.

💬

Chatter, Your Way

Switch the chatter between the side (Odoo default) and always-at-the-bottom modes from a single setting. When on the side, drag the left edge to resize — double-click to reset. Width is remembered per browser.

☷

Per-Column List Filters

A smart filter row appears under every list view header. Type to filter char/text/many2one fields, pick values for selection & boolean columns, use native pickers for dates and numbers. All server-side, debounced, and survives search-bar changes.

📱

Tablet & Mobile Ready

Sidebar shrinks gracefully on tablets and turns into a slide-in drawer with a floating hamburger toggle and tap-to-dismiss backdrop on phones. Content area reclaims the full viewport, and menu taps auto-close the drawer so navigation feels native on any device.

How it works

Configuration-first architecture. Zero code edits to customize.

1

Install

Drop the module into your addons path, then ./odoo-bin -u ethara_etp_theme.

2

Configure

Open Settings → Ethara Theme. Tweak colors, fonts, density, sidebar, login. Hit Save.

3

Enjoy

CSS variables flow site-wide. The whole backend reflects your brand instantly.

Compatibility

Odoo 19.0 Community Odoo 19.0 Enterprise Chromium Firefox Safari LGPL-3

Backend-only theme. Does not touch the website / e-commerce frontend. Depends only on web and base_setup.
